📊 나이스 시장조사 자동입력

나이스에서 내려받은 시장조사자료등록 파일과 업체가 단가를 적어 보낸 현품설명서를 올리면, 식품명으로 자동 매칭해서 조사가1·2·3이 채워진 나이스 업로드용 엑셀을 만들어 드려요. (컴퓨터 안에서만 처리되고 서버로 전송되지 않아요)

1나이스 시장조사자료등록 파일

클릭하거나 파일을 끌어다 놓으세요 — 나이스 [시장조사자료등록] 화면에서 내려받은 .xlsx
📌 나이스에서 이 파일 내려받는 법 (처음이시면 펼쳐보세요)
  1. [식단] → 시장조사자료등록 → 조회 → 추가
  2. 시장조사일자 선택, *시장조사장소1 입력 ← 필수! 비우면 “시장조사장소1은 필수입력입니다” 알림이 뜹니다
  3. 급식일자 범위 선택 → 조회
  4. 식품 전체선택 → 자료내려받기

⚠️ 업로드하면 그 조사일자의 기존 시장조사정보는 삭제되고 교체됩니다. 업체별로 나눠 여러 번 올리면 앞의 것이 지워지니, 조사가1·2·3을 한 파일에 담아 한 번에 올리세요.
⚠️ 주사용식품으로 등록되지 않은 식품은 업로드에서 제외됩니다. 빠진 품목이 있으면 [내식품정보]에서 주사용식품여부를 ‘예’로 바꾼 뒤 다시 내려받으세요.

파일 올리기

3매칭 결과 확인

📌 만든 파일을 나이스에 올리고 품의까지 넘기는 법
  1. [시장조사자료등록]에서 자료올리기 → 만든 파일 선택 → 확인
    “조사일자 ○○의 시장조사정보는 삭제되고 교체됩니다” 는 정상 문구예요.
  2. 저장
  3. 식품 전체선택 → 예정단가반영
    적용가가 [예정단가등록]으로 넘어갑니다. ‘최저가선택’은 누르지 마세요 — 비어 있는 조사가2·3의 0을 최저가로 잡아 적용가가 0이 되고, “적용가는 0보다 커야 합니다” 오류가 납니다. (적용가는 이 도구가 이미 채워뒀어요)
  4. [예정단가등록]으로 이동 → 예정단가식단반영 클릭
  5. 팝업에서 급식일자·식사구분 확인 → 반영대상에 ‘식단’ 체크 (식재료품의를 이미 만들었다면 ‘품의’도 체크) → 반영
    ⚠️ 품의작성에서 단가를 손으로 입력해 둔 게 있으면 이 반영으로 덮어써집니다.
  6. [식재료품의작성]에서 단가 0인 식품, 공산품 소수점 발주가 없는지 확인 후 품의처리

💡 예정단가가 품의에 안 붙으면 공통식품코드·규격·단위가 예정단가등록 식품과 품의 식품 사이에 어긋난 경우예요. 이번에 조사하지 않은 품목은 예전 조사일자의 단가가 그대로 남아 있으니 조사일자도 함께 확인하세요.
